# Artwork provenance

Built-in image generation; reference is the owner's A/B/C Y2K concept board, C ultraviolet/silver biomechanical pod. Generated 1086 × 1448 RGBA asset is `public/assets/pod.png`.

Prompt: Create one production-ready transparent PNG asset, ONLY skin C from reference: ultraviolet / silver biomechanical video pod. Preserve exuberant sculptural Y2K chrome ribs, coiled purple tubes, oval amethyst lenses and asymmetric organic silhouette. Straight-on flat front view, NOT angled perspective. ONE device only, no board, no labels outside, no state samples. Large portrait device centered, edges fully visible with little transparent margin. Crucial: actual alpha transparency outside silhouette AND inside the large central rectangular video aperture. Aperture has NO video image, NO glass, NO black fill and NO checkerboard. Keep aperture rectangular, about x23%-84% and y24%-61% of total image. Keep surrounding shiny purple-chrome bezel. Lower controls: one broad dark purple horizontal seek groove at y66%, then FIVE large blank purple oval buttons in a row at y74%, then three broad blank pill-shaped purple buttons at y83%. On right edge a tall dark purple vertical volume groove. No readable words, no baked icons, no timer. Blank buttons will receive actual HTML controls. Chrome biomechanical flourish at top and bottom. Exact C identity, elegant coherent futuristic artifact.

Actual generated geometry was measured and implementation follows that geometry rather than prompt coordinates. Image center pixel (550,500) is RGBA (0,0,0,0). Outer corner is also alpha 0. Artwork was inspected directly; no icon ghosts remain in sockets.

## Illustrated control state atlases

Following the owner's explicit sprite-sheet correction, three additional image-generated atlases replace CSS materials and vector/Unicode icons. Every control has separate normal, hover, pressed, cyan focus, and disabled artwork. `artwork-source/transport-states.png` contains backward, play, pause, stop, forward, fullscreen. `switch-states.png` contains CC OFF/ON, LOOP OFF/ON, SOUND ON/OFF. `thumb-states.png` contains an amethyst seek diamond and violet volume bead.

Prompts required original C ultraviolet glass with thin polished chrome rims, fixed six-column/five-row registration for buttons, two-column/five-row registration for thumbs, actual alpha, baked icons/labels, and distinct raised/illuminated/recessed/focus/unlit material states. The switch atlas was refined to three-to-one capsule proportions instead of squashing the first generated version. Final original atlases are included, along with exact per-cell crop coordinates in `public/assets/sprites/manifest.json`. `scripts/slice-sprites.py` reproduces all 70 slices without recoloring or synthesizing button appearance. CSS selects the appropriate image; it does not render the glass, symbols or focus halo. Native keyboard outlines remain as accessibility reinforcement.
