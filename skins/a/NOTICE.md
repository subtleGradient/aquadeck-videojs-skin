# Notices and provenance

LIQUID ORBIT is an original Video.js skin created for Thomas with AI assistance. Source and original skin artwork are licensed under Apache License 2.0.

The shell was regenerated using OpenAI's built-in image generation tool from the owner's A / Electric Aqua / Chrome Liquid Spaceship concept. The production PNG preserves genuine alpha transparency around the shell and inside its video opening. The reference board is retained locally for design verification, not required at runtime.

Prompt: Generate one front-on liquid chrome/electric aqua spacecraft chassis based only on concept A. Preserve sculpted asymmetric pointed fins and glass pearls. Fully transparent exterior and video aperture; blank control deck and volume well; no baked icons, numbers, text or button sprites.

The demo's original 24-second motion study, poster and visual-description captions are reused from the owner's AQUADECK project. The media is demonstration content, not part of Video.js.

Video.js (@videojs/html 10.4.0) is open-source software by its contributors, distributed under Apache-2.0. Vite is MIT-licensed build tooling. Dependency license files remain in their distributions; these components are not relicensed by this project.

The `public/buttons/states.png` and `additional.png` sprite sheets were regenerated with the built-in OpenAI image tool to match the reference board's A control artwork. Five genuinely different rendered states are supplied for each control: normal, hover, pressed, focus and disabled. `slice-sprites.py` records deterministic crops into individual PNGs. The pressed/focus/disabled appearances are artwork, not CSS shading/filter approximations. Native HTML buttons remain the interaction layer. SVG is retained only as a forced-colors accessibility fallback.
